## CIIR–CRS–RIC Closed Loop (verified present)

```mermaid
sequenceDiagram
  participant W as World/Sensors
  participant Obs as StateObserver (realworld_bridge/observer.py)
  participant CIIR as Constraint Layer (ciir_crs_ric/ciir.py)
  participant RIC as Reality Interface Controller (reality_interface.py / v2)
  participant CRS as Action Translator (ciir_crs_ric/crs.py)
  participant Gate as Constraint Gate (mvri/constraint_gate.py + safety_gate.py)
  participant Act as Actuator (realworld_bridge/actuators.py)
  W->>Obs: observation
  Obs->>CIIR: phi(state)
  CIIR->>RIC: projected state + Inv predicate
  RIC->>CRS: parsed intent
  CRS->>Gate: candidate action a
  Gate-->>CRS: validate (MAG/TGT/ROC/MVR + ER/CS/SS/IC/AUD)
  Gate->>Act: accepted action
  Act->>W: side-effect
  Act->>Obs: trace entry
```
