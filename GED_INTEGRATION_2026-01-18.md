## GPS COMPLIANCE FRAMEWORK

### GED-DOCUMENTED vs. GPS-VERIFIED DISTINCTION:

**GED-DOCUMENTED:**
- Ancestor appears in GEDCOM file (family tree compilation)
- Represents compiled family research from various sources
- Secondary source (not original documentation)
- REQUIRES independent verification via primary sources
- Status indicator: 📜

**GPS-VERIFIED:**
- Ancestor proven via original primary source documents
- Meets BCG Genealogical Proof Standard (5 criteria)
- Contemporary records or near-contemporary evidence
- Multiple corroborative sources preferred
- Status indicator: ✅

**NOT YET VERIFIED:**
- Has not been researched in primary sources
- Requires elevation from GED to primary documentation
- Cannot be claimed as "proven" under GPS
- Status indicator: ❌

### BCG GENEALOGICAL PROOF STANDARD (5 Criteria):

For 17th century York ancestors to be GPS-certified:

1. **Reasonably Exhaustive Research**
   - Systematic search of relevant repositories
   - Colonial records: Virginia, Maryland, Pennsylvania
   - English records (if immigrant origin confirmed)

2. **Complete Citations**
   - Full source documentation with repository information
   - Enable independent verification by other researchers

3. **Thorough Analysis**
   - Critical evaluation of evidence quality
   - Cross-correlation of multiple sources

4. **Conflict Resolution**
   - Address contradictions or ambiguities
   - Explain reasoning for conclusions

5. **Sound Conclusion**
   - Logical inference from assembled evidence
   - Appropriate confidence level stated
